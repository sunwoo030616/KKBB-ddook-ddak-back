# 사용자 승인 기준 재집계: 기존 조건부도 모두 유효

기존100문항의 모델 응답은 그대로 두고 사용자가 승인한 조건부 유효(C)를 모두 유효 정답으로 집계했다. 목표 지원 부족·명시된 완료/제외 조건 위배(N)는 유지했다. 모델 재실행 및 새 API 비용 없음.

| 지표 | E5→JEV 개선판 | LLM 단독 | JEV 단독 |
|---|---:|---:|---:|
| 유효 메뉴 최소1개 | 100% | 98% | 100% |
| 유효 메뉴 최소2개 | 100% | 64% | 100% |
| 유효 메뉴 최소3개 | 85% | 42% | 90% |
| 추천 메뉴 중 유효 비율 | 95.00% | 87.76% | 96.67% |
| 전체 추천 수 | 300 | 294 | 300 |

## 해석과 재현

- 100%는 이100문항에서 유효 메뉴를2개 이상 포함한 비율이다. 전체 업무 완수율이나 독립 전문가가 검증한 정확도가 아니다.
- 같은 역할의 서로 다른 메뉴ID도 각각 유효 메뉴로 센다. 서로 다른 업무2개 완수와 다르다.
- LLM 단독은0~8개(평균2.94개)이며28문항에서2개 미만을 제시했다. 다른 두 모델은3개씩이다. 출력 예산을 통일한 신규 실험이 아니므로 모델 능력 우열로 일반화하지 않는다.
- 앞3개 제한 시 LLM의 최소2개 유효는60%이며 전체 응답64%와 구분한다. 응답 순서는 보장된 관련도Top3 순위가 아니다.
- 기존10개상황×10개표현을 대상으로 한 사후 사용자 승인 평가다. 이전 정답표와 판정 이력은 보존했다.
- 시간·비용은 이전 실측 그대로다. E5→JEV 평균0.753초/P950.931초/$0.11344, LLM1.273초/1.708초/$1.48537, JEV1.527초/2.091초/$0.64225. 비용은100문항 API추정이고 서로 다른 시점 측정이다.

`python experiments/utility-review-100-v3/define_review.py` → `python experiments/utility-review-100-v3/score.py` → `python experiments/utility-review-100-v3/build_report.py`로 오프라인 재현한다. build_report는 이 finalize_report까지 실행한다. 추가 API호출 없음.

review-rules.json의 changes_from_v2에 모든 변경과 이전 이유를 보존한다. answers.html에서 질문·모델답·판정 이유를 확인한다.
