# 사용자 승인 기준 재집계: 기존 조건부도 모두 유효

기존100문항의 모델 응답은 그대로 두고 조건부 유효(C)를 모두 유효 정답으로 승격했다. 목표 지원 부족·명시된 완료/제외 조건 위배(N)는 유지했다. 모델 재실행 및 새 API 비용 없음.

| 지표 | E5→JEV 개선판 | LLM 단독 | JEV 단독 |
|---|---:|---:|---:|
| 유효 메뉴 최소1개 | 100% | 98% | 100% |
| 유효 메뉴 최소2개 | 100% | 64% | 100% |
| 유효 메뉴 최소3개 | 85% | 42% | 90% |
| 추천 메뉴 중 유효 비율 | 95.00% | 87.76% | 96.67% |
| 전체 추천 수 | 300 | 294 | 300 |

## 해석

- 100%는 이100문항 모두에서 승인된 유효 메뉴를2개 이상 포함했다는 뜻이다. 전체 메뉴·업무를100% 맞췄다는 뜻이 아니다.
- 유효 메뉴2개는 서로 다른 업무2개 완수와 다르다. 유사 기능의 별도 메뉴ID도 각각 유효 메뉴로 센다.
- LLM 단독은0~8개(평균2.94개)를 추천했고28문항에서2개 미만을 제시했다. 다른 두 모델은3개씩 추천했다. 추천 개수를 통일한 신규 실험이 아니므로 모델 자체의 능력 우열로 일반화하지 않는다.
- LLM 응답 앞의3개만 보는 보조 집계에서 최소2개 유효는60%다. 전체 응답 집계64%와 구분한다. 앞3개는 보장된 관련도Top3 순위가 아니다.
- 이는 기존10상황×10표현에 대한 사용자 승인 기반 사후 재평가다. 독립 전문가의 사전 고정 벤치마크가 아니다. 기존 정답표와 이전 버전 결과는 보존했다.
- 시간·비용은 기존 실측과 동일하다. E5→JEV 평균0.753초/P950.931초/$0.11344, LLM단독1.273초/1.708초/$1.48537, JEV단독1.527초/2.091초/$0.64225. 비용은100문항 API추정이고 서로 다른 시점 측정이다.

v2의 조건부 판정 31개 상황/메뉴 쌍을 일괄 유효로 바꾸고 동일하게 세 모델에 적용했다. 변경 목록과 이전 이유는 review-rules.json에 보존했다.
