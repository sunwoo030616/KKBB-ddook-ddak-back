## 측정 방법

같은 기존 100문항·정답/허용 메뉴 집합·모델 jev-1.14.0을 사용했다. 정답은 inference payload에 전송하지 않았다. JEV 단독은 전체585개를80개씩7묶음과25개1묶음으로 나누고 최대4개 묶음을 동시에 평가했다. 묶음마다 평가한 모든585개 Noul을 합친 뒤, 0.30이상 전역 상위10개를 고르고 기존 코드와 동일한120개 3종 조합 Choice를 적용했다. E5 임베딩·검색·MMR은 사용하지 않았다. 점수가 같으면 카탈로그 순서를 사용했다.

부분 적중은 허용 메뉴가 하나 이상 포함된 문항 비율이며 추가 오답이 있어도 적중으로 센다. 정확한 전체 업무 처리율과 다르므로 허용 메뉴 비율과 필수 업무 Recall, 완전일치도 함께 표시한다.

## 비교의 한계

- E5→JEV 기준은 기존 실측이며 이번과 동시에 재실행한 결과는 아니다. 네트워크·제공자 부하에 따른 시간 차이가 섞인다.
- JEV 단독 시간은4개 청크 동시 실행을 포함한 한 질문 전체의 실제 경과시간이다. 청크 시간을 더하거나 단일 API 요청 시간으로 오해하면 안 된다.
- E5를 완전히 제외하기 위해 MMR도 제외했다. 이 비교는 두 시스템 전체의 비교이고, 검색만의 인과 효과를 분리한 실험이 아니다.
- 각 청크의 문맥이 달라 Noul 점수의 청크 간 비교 가능성이 완벽히 보장되지는 않는다.
- 기존100문항은 이전 개발 과정에 노출된10상황×10표현이다. 새로운100개 상황이나 실제 서비스 일반화 검증이 아니다.
- 비용은 성공 응답의 실제 input_tokens에 공식 $0.042/백만 토큰을 곱한 추정치다. output은무료. 실패 한도시도는 비용 합계에서 제외하고 원시로그에 보존한다. CPU/운영비·세금은 제외한다. 성공 호출이 발생한 실패 문항이 있으면 그 성공 호출 사용량은 비용에 포함한다.

요청 시도 900회, 성공 900회, 문항 오류 0건. 실제 청구서 금액은 아니다.
