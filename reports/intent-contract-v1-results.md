# 검색 전 LLM 의도 계약 결과

같은 로컬 Qwen3-4B와 MPS float16 검색 모델을 사용했다. 기존 실패를 보고 개발한 기능이며 작은 내부 진단 자료다. 외부·독립 벤치마크가 아니다.

| 자료 | 기존 intent off | intent auto |
| --- | ---: | ---: |
| 기존 12개 회귀 | 11/12 | 11/12 |
| 실행 전 고정한 새 8개 표현 | 8/8 | 8/8 |

새 표현의 지연 중앙값: off 10.68초, auto 15.67초. 순차 실행·캐시·장비 부하가 있어 엄밀한 처리량 실험이 아니다.

원문 구간을 원하는 일·제외 조건·상황으로 분류해 검색에 반영한다. 구간 ID의 출처 검증은 의미 판정이 항상 옳다는 보장은 아니다.

## 해석

- 기존 회귀 개선: s08; 악화: s10.
- 새 표현은 첫 의도 계약 추론 전에 파일과 해시를 고정했다. 개발자가 작성했고 이전 문제를 알고 있었으므로 외부 검증셋으로 부르지 않는다.
- 정답 위젯 목록은 평가기에만 전달했다. 전체 이전 대화는 모델이 재생성한 것이 아니라 동일한 화면 fixture를 사용했다.
- 긍정 요청이 없는 새 화면은 확인 안내를 반환한다. 삭제만 있는 후속 요청은 기존 위젯 범위에서 편집한다.
- 혼합 구간은 내용 손실을 피하려고 검색에 남긴다. 규칙 기반 분할·부정 범위·간접 요청에는 실패 가능성이 있다.
- 검사 자료에는 추가 LLM 호출로 인한 지연도 포함했다. 일반적인 모든 질문에서 정확도나 속도가 개선된다고 주장하지 않는다.
- 의도 계약 trace 상태: {'validated': 16}.
