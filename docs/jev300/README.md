## 수치의 의미

단일 업무는 정답 메뉴 ID의 정확 일치가 성공이다. 확인 요청·no_match·오류도 실패로 분모에 포함했다. 복수 업무는 현재 운영 정책에 따라 메뉴를 선택하지 않고 확인을 요청해야 성공이다. 서로 다른 판정 기준을 합친 전체 정책 준수율을 ‘300문항 메뉴 정확도’로 표현하지 않는다.
단일 업무에서 실제 메뉴를 반환한 268건만 조건부로 보면 일치율은 99.6269%다. 이 수치는 확인 요청을 제외하므로 전체 단일 업무 정확도를 대신하지 않는다.

공개 API의 needs_clarification에는 원시 unsure와 confidence<0.6이 함께 포함된다. 이번 결과로 모델이 원시 unsure를 몇 번 선택했는지, 되묻기 내용이 적절한지는 알 수 없다.

## 한계와 검증

- 기존 합성 질문과 목표 ID를 재사용했다. 독립적으로 수집·검수한 실사용 질문 평가가 아니므로 운영 정확도 보장이나 이전 20문항 대비 개선율로 일반화하지 않는다.
- 실패 문항의 정답은 그대로 보존했다. 단일 라벨이 대체 정답을 빠뜨리거나 확인 요청이 합리적인 문항이 있을 수 있지만, 독립 재검수 없이 점수를 올리도록 라벨을 바꾸지 않았다.
- 두 업무 질문은 기존 합성 문장 두 개를 이어 붙인 30건이다. 자연스러운 복합 질문 전체를 대표하지 않는다. 한 번의 되묻기 이후 최종 메뉴 선택·대화 성공·GenUI·거래 실행은 측정하지 않았다.
- 시간은 모델 로딩을 제외한 로컬 백엔드 HTTP 왕복이며 실제 외부 JEV 지연을 포함한다. 운영 부하·반복 실행 변동성은 미측정이다.
- 로컬 지표 테스트 4개, 운영 메뉴 검색/선택·컨트롤러 테스트 10개 통과. 저장한 300개 응답의 점수·입력 해시·유형/영역 집계를 verify.py로 재검산했다.
