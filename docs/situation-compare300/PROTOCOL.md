# 상황별 복수 메뉴 추천과 전체 메뉴 LLM 비교: 실행 전 조건

사용자의 일본 여행 예시는 환전·해외 QR 결제·여행자보험을 모두 제안해야 성공이다. 단순 확인 요청은 성공이 아니다. 585개 활성 메뉴에서 최대 3개를 추천하는 새 /api/menus/recommend 경로와 전체 메뉴 LLM을 비교한다. 앞선 단일 선택 비교는 사용자 범위 변경으로 191쌍에서 중단했으며 이번 결과와 합치지 않는다.

## 데이터와 판정

300개 합성 질문: 단일 요청 100, 명시적 2~3개 업무 100, 상황형 묶음 100. 단일 라벨은 이전 세트에서 결과와 무관한 일정 간격으로 100개 선택하고, 명시적 복수는 이를 고정 규칙으로 결합했다. 상황형은 사전 작성한 20개 업무 묶음의 5개 표현 변형이다. 정답은 실행 전에 cases.json과 SHA256으로 고정한다. 일본 여행 예시는 제품 정책 개발용 smoke에 사용됐다. 300개가 300개의 독립 의도라는 뜻은 아니며 전문가 검수·실제 사용자 표본이 아니다.

메뉴 집합 정확 일치, 상태+집합 일치, 질문별 평균 Precision/Recall/F1, 전체 메뉴 개수 기준 micro P/R/F1, 누락·추가 메뉴 수를 보고한다. 메뉴 순서는 무시하고 중복 ID는 허용하지 않는다. 오류와 확인 요청은 분모에 남기며 정답 묶음 대신 확인만 반환하면 실패다. 전체가 지원되는 positive 요청이므로 모호·무관한 요청의 판별 성능은 이 실행에서 평가하지 않는다.

## 비교 조건

- E5→JEV: jev-1.14.0 업무 판단 1회 → 각 업무의 실제 E5 검색 → 메뉴·제안 근거 판단 1회. 조기 확인/no_match이면 1회다. 단일 업무 Top-40, 복수 업무별 Top-12. 합계 최대 600 JEV 호출을 실제 집계한다.
- LLM 단독: gpt-4o-mini-2024-07-18, E5 없이 동일 585개 메뉴 필드와 실제 운영 요청에서 캡처한 업무 정책·정의·선택 정책을 전달한다. 최대 3개 메뉴 슬롯과 confidence/basis를 strict JSON Schema로 받는다. temperature=0, max_tokens=500. 질문당 외부 호출 1회, 합계 300회다.
- 질문별 두 조건의 실행 순서를 교대한다. 조건당 1회, 재시도 없음. 3회 연속 provider 오류면 중단해 부분 결과를 보존한다. 결과를 보고 정책·프롬프트·정답을 바꾸지 않는다.
- confidence 기준은 양쪽 0.6이지만 척도는 서로 보정되지 않았다. JEV는 계획과 메뉴 판단의 confidence를 사용하고 GPT는 출력 슬롯의 자체 보고 값을 사용한다. 전체 제품 구조 비교이며 모델만을 교체한 절대 우열 평가가 아니다.

## 시간·토큰·실행 보호

로컬 HTTP 요청부터 응답까지 평균·중앙값·P95를 측정한다. JEV의 두 외부 호출·E5 질의·JVM·usage 기록 프록시와 GPT 경로의 Python 구성·직렬화·외부 API·검증을 포함한다. 기동·컴파일·메뉴 임베딩 준비는 제외한다. 캐시·첫 스키마 처리 효과를 제거하지 않는다. 토큰 예산 대기는 별도 queue_wait_ms로 기록하고 응답시간에서 제외한다.

실제 API 반환 usage의 입력·출력·캐시를 호출별 저장하고 문항당 모든 단계의 사용량을 합친다. 미제공 값은 null이며 추정하거나 0으로 대체하지 않는다. 캐시 토큰은 입력 토큰에 포함된 부분집합이다. 제공자 tokenizer/usage 정의가 달라 동일 청구 금액·연산량으로 환산하지 않는다. E5 로컬 연산량은 JEV API 토큰에 포함되지 않는다.

임시 소스 복사본의 JevDecisionClient endpoint와 대응 테스트 예상 URL만 loopback usage 프록시로 바꾼다. 원본 코드와 판단 규칙은 바꾸지 않는다. 전체 기존 Java 테스트를 먼저 실행한다. 키는 환경 변수/기존 IntelliJ 설정에서 메모리로만 읽으며 저장하지 않는다. 새 300문항 및 전체 메뉴의 OpenAI 전송은 자동 승인 검토의 재승인 요구에 따라 사용자 승인을 대기한다.

재현: 기존 E5 모델을 준비하고 OPENAI_API_KEY/JEV_AI_API_KEY를 설정한 뒤 다음을 실행한다. 완료 결과는 덮어쓰지 않는다.

```sh
python3 -m unittest discover -s scripts/semantic/situation_compare300 -v
python3 scripts/semantic/situation_compare300/run.py \
  --e5-python /path/to/e5-venv/bin/python --model-dir /path/to/e5-model \
  --output /tmp/new-situation-comparison/results.json
```
