## 읽는 방법과 한계

- 메뉴 집합 정확 일치는 필요한 모든 메뉴를 골랐고 불필요한 메뉴를 추가하지 않은 경우다. 순서는 무시한다. 일본 여행 묶음에서 환전·QR·보험 중 하나라도 빠지면 정확 일치는 실패다. 확인 요청도 이 positive 정답을 대신할 수 없다.
- Precision은 반환한 메뉴 중 정답 비율, Recall은 필요한 메뉴 중 찾은 비율이다. Macro는 질문별 값을 평균하고 Micro는 전체 TP/FP/FN을 합쳐 계산한다. F1은 Precision과 Recall의 조화평균이다. 이번 Recall은 최종 반환 메뉴에 대한 값이며 기존 E5 후보 Recall@40과 다르다.
- E5 쪽은 JEV 업무 판단과 메뉴 선택을 최대 두 번 호출한다. 토큰과 시간에 두 단계가 모두 포함된다. GPT는 검색 없이 전체 카탈로그를 받아 한 번 응답한다. 모델만 교체한 통제 실험이나 9종 위젯 비교가 아니다.
- GPT 모델은 gpt-4o-mini-2024-07-18, JEV는 jev-1.14.0이다. 공통 confidence 기준은 0.6이나 척도·보정은 같지 않다. GPT 전용 프롬프트 최적화나 모델별 임계값 보정은 하지 않았다.
- 입력·출력·캐시 토큰은 API의 실제 usage다. 캐시는 입력의 부분집합이며 미제공은 0이 아니다. 제공자 tokenizer와 usage 정의가 다르므로 금액·연산량 차이로 같은 비율 환산하지 않는다. E5 로컬 추론은 JEV API 토큰에 포함되지 않는다.
- 시간에는 각 제품 경로의 로컬 구현·네트워크·스키마 처리·캐시 효과가 포함된다. 컴파일·모델 시작·메뉴 벡터 준비·명시적 토큰 예산 대기는 제외했다. 단일 순차 실행이며 부하 성능이나 통계적 유의성을 주장하지 않는다.
- 100개 단일 요청은 과거 질문을 재사용했고 100개 명시적 복수 요청은 이를 결합했다. 상황형 100개는 20개 가족의 표현 5종이다. 독립 의도 300개가 아니며 일본 여행은 개발용 정책 확인 예시다. 전문가 독립 검수·실제 고객 표본이 아니다.
- 현재 지원은 최대 3개 업무와 54개 업무 정의/fallback이다. 같은 fallback에 해당하는 복수의 미지원 업무를 모두 분리하지 못할 수 있다. 모든 메뉴를 호출하거나 화면을 구현한 것은 아니다. 모호·무관한 negative 요청, 설명 품질·이후 대화·실제 거래는 이번 300개에서 평가하지 않았다.
- 앞선 단일 선택 300문항의 98.89% 및 확인 요청 100%와 과제가 달라 직접 개선·하락으로 비교하지 않는다. 중단한 단일 선택 비교 191쌍은 이번 점수와 합치지 않았다.
