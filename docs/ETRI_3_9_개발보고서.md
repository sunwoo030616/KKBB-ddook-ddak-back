# 깨비뚝딱: 문서 근거·검색 도구·로컬 서빙 개발 보고서

2026-11-04 추가 개발. 기존 수상작과 구분하는 개인 후속 개발이며 실제 금융 거래는 수행하지 않는다.

## 제품과 구현

채팅 상황 → 화면 초안 → 서버 컴파일 → 문서 근거 검색·바인딩 → 금융 위젯 렌더링 흐름이다. 일반 Q&A 챗봇으로 제품을 바꾸지 않았다.

- 기존 로컬 Qwen3-4B 4bit와 BGE reranker를 재사용한다. 유료 생성 API를 호출하지 않았다.
- 모델이 허용 주제 안에서 검색어·검색/확인 요청/종료를 선택한다. adaptive는 누락된 주제에 한해 최대 한 번 더 검색한다.
- 서버가 기관·기준일·문서 ID·주제를 재검증하고 검수 corpus의 텍스트를 그대로 바인딩한다. 근거 존재와 답변의 의미적 정확성은 다르다.
- 결제카드 해제와 은행 보안카드·OTP 해제를 구분한다. 계산 폼 변경은 모델을 다시 호출하지 않고 기존 근거·입력을 유지한다.
- 프론트는 원문 링크·절·기준일과 자료 부족 상태를 표시한다. 금융 계산은 기존 Decimal 도구를 사용한다.

## 문서 처리·버전 관리

- 공식 페이지 6개의 원문 해시·변경 여부·추출 후보를 만들었다. 원문과 미검수 후보는 ignored var/에 보관한다.
- 별도 검수 자료 4개는 원문 위치·해시·주제를 확인했다. 보안장치 안내를 일반 결제카드 안내로 승격하지 않는다.
- 실제 서비스 corpus는 기존 검수 요약 8개 출처·26청크다. 추출 후보를 자동 승인하거나 corpus가 확대됐다고 주장하지 않는다.
- DocumentStore는 검증된 원본 bundle을 버전별 보관하고 원자적으로 복원한다. RAG_REFRESH_CORPUS=1로 명시적 갱신 가능하다.

## 검색 비교 결과

40문항은 개발 24개·최종 확인 16개이며 8가지 조건의 유사 표현 변형이다. 독립 표본 40개나 외부 블라인드 평가로 해석하지 않는다. 정답은 기관·시점·등록 주제의 검색 가능 범위이며, 자연어 답변의 의미 정확도를 평가하지 않는다. 전체 대화·화면 평가는 별도다.

| 자료 | 방식 | 기대 주제 집합 일치 | 누락 주제 일치 | 오류 | 중앙값(초) |
| --- | --- | ---: | ---: | ---: | ---: |
| dev | once | 24/24 | 24/24 | 0 | 8.63 |
| dev | adaptive | 24/24 | 24/24 | 0 | 10.11 |
| test | once | 16/16 | 16/16 | 0 | 7.36 |
| test | adaptive | 16/16 | 16/16 | 0 | 8.98 |

기본값은 개발 결과를 보고 once로 선택했다. adaptive는 추가 회수 이득이 입증되지 않아 실험 옵션으로 남겼다. 실행 순서·열 상태·장비 부하가 있어 지연 수치의 작은 차이를 엄밀한 인과 효과로 해석하지 않는다.

## 서빙·백엔드

단일 worker 큐의 중복 제출 방지, 큐 용량·대기 예산, SQLite 작업 상태 저장, 재시작 중단 표시를 구현했다. 중단된 작업은 자동 재실행하지 않는다. 큐 대기·단계별·전체 시간을 분리하며 동적 스키마 생성기 캐시도 64개로 제한했다. 실행 중 추론의 강제 취소나 분산 큐를 구현한 것은 아니다.

원문 사용자 요청은 작업 DB에 저장하지 않는다. 화면 결과·입력값은 로컬 화면/작업 DB에 TTL로 남을 수 있다.

| 동시 요청 | 제출 수 | 작업 완료 | 유효 화면 | p50(초) | p95(초) | 처리량(req/s) |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 8 | 8 | 8 | 8.52 | 10.95 | 0.111 |
| 2 | 8 | 8 | 8 | 16.84 | 17.11 | 0.119 |
| 4 | 8 | 8 | 8 | 33.05 | 34.89 | 0.118 |

대출 상환표·예금보호 두 종류 요청을 반복한 작은 로컬 표본의 탐색적 측정이다. 서버 화면 구성 경로를 분리하기 위해 evidence_mode=off로 실행하며, 근거 검색 포함 전체 화면은 별도로 검증한다. p95는 표본 수가 작아 불안정하다. 대규모 트래픽·분산 학습·이종 가속기 통신 최적화 성과로 표현하지 않는다.

## 과학문헌으로의 전이 실험

Crossref에서 25건의 학술·출판 메타데이터(프리프린트·학위논문 등 포함)를 수집하고 DOI 정규화·중복 제거·SQLite FTS 검색을 실행했다. 별도 /research/papers는 같은 로컬 모델이 제목 키워드 검색과 관측된 DOI 조회를 최대 3단계 선택한다. 본문 이해·논문 요약·학술적 관련성 정확도를 입증한 것은 아니다.
