# 개발 결과 저장 오류 — 평가 점수에서 제외

첫 개발 요청 후 상대 입력 경로를 절대 ROOT 경로 기준으로 계산하는 저장 처리에서 실패했다. 모델 응답의 점수와 usage가 저장되지 않았으므로 임의로 복원하지 않는다. 외부 호출은 최대 3회로 승인된 개발 예산에 보수적으로 계산한다. 대규모 평가는 이 시점에 시작하지 않았다.

입력 경로를 시작 시 절대 경로로 바꾸고, 첫 API 호출 전에 빈 보고서 저장을 검증하도록 수정했다. 이후 각 API 응답의 usage를 upstream-calls.jsonl에도 즉시 보존한다. 업무 정책·질문·정답·모델·임계값은 변경하지 않았다.
