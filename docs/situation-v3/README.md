# 일반 복수 업무 선택 v3 실제 검증

경로: GPT-4.1 업무 분해 → 실제 E5 검색 → 업무별 JEV 선택. 새 경로에 여행·국가·상황별 고정 메뉴 묶음은 없다. 기본 추천 API도 일반 경로에 연결했다. 실제 사용자 화면/거래에 배포한 상태는 아니다.

## 새 고정 복수 업무 100문항 — 완료

단일 질문을 섞지 않은 합성 평가다. 명시적 복수 50개는 실제 메뉴 이름 조합으로 2~5개 업무를 요청한다. 상황 설명형 50개는 25개 의도군의 두 표현이며 원하는 기능적 결과가 문장에 드러난다. 새로운 문장 표현이지만 기존 메뉴·의도와 중복될 수 있다. 전문가 독립 라벨이나 실제 트래픽 평가는 아니다.

| 구간 | 상태+전체 메뉴 정확 일치 | 오류 |
|---|---:|---:|
| contextual_multi | 45/50 · 90.00% | 2 |
| explicit_multi | 50/50 · 100.00% | 0 |
| 전체 | 95/100 · 95.00% | 2 |

정확 일치는 필요한 메뉴를 모두 고르고 불필요한 메뉴가 없으며 상태도 맞아야 한다. 부분 일치를 정확 일치로 바꾸지 않았다. 형식 오류 2건도 실패에 포함했다. 명시적 복수 50/50, 상황 설명형 45/50이다. 이 90%는 자유로운 상황 추천 전체가 90%라는 뜻이 아니다.

Macro P/R/F1: 96.33% / 96.50% / 96.40%. 누락 7개, 추가 4개.

## 시간과 토큰 — 추가 LLM 포함

전체 100요청 평균 HTTP 1,718.82ms. 성공 응답 평균/P95 1,725.04/2,173.59ms. 컴파일·모델 기동은 제외하고 요청 중 LLM/E5/JEV/proxy 처리는 포함했다.

| 역할 | 호출 | 입력 합계 | 출력 합계 | 요청당 입력/출력 |
|---|---:|---:|---:|---:|
| e5_jev | 98 | 713,426 | 82,644 | 7,134.26 / 826.44 |
| llm_task_planner | 100 | 1,725,629 | 8,763 | 17,256.29 / 87.63 |

전체 요청당 입력/출력은 24,390.55/914.07토큰이다. OpenAI 캐시 입력 1,560,064토큰은 입력의 일부이며 별도로 더하지 않는다. 제공자별 토큰을 동일 비용 단위로 해석하지 않는다. 순수 E5/JEV의 속도·비용 개선으로 표현하지 않는다.

## 기존 300문항 회귀 — 잔액 소진으로 미완료

24/300문항을 시도했다. 18개는 모델 응답을 받았고 6개는 OpenAI HTTP 429로 중단됐다. 300개 전체 정확도는 아직 없다. 현재 부분 기록은 raw results.json에 남아 있으며 300개 성능으로 인용하면 안 된다.

추가 진단에서 실제 오류 code=credit_balance_exhausted, type=insufficient_quota, message=You have no credits remaining이 확인됐다. 최초의 분당 제한 설명은 잘못됐으며, 대기나 속도 조절로 해결되지 않는다. 잔액 충전이 필요하다. 기존의 실제 메뉴 오류와 상태 불일치는 그대로 보존한다.

사용자는 한도 오류 문항의 재실행·최종 결과 교체와 해당 오류 시도의 최종 토큰 합계 제외를 요청했다. 따라서 HTTP 429 6회는 비교 토큰 합계에서 제외했다. 이 응답들은 usage를 반환하지 않았으므로 임의의 토큰 수나 0토큰을 만들지 않았다. 원본은 regression/quota-failures-original.json과 upstream-calls.jsonl에 보관했다. 충전 후 성공한 재호출 사용량은 최종 합계에 포함해야 한다. 아직 잔액이 없어 재실행하지 못했다.

## 남은 오류·검증·범위

- 새 100개의 실패는 5건이다. 2건은 계획 유효성 오류, 3건은 휴양림 예약 세부 종류 추가·숙박을 캠핑으로 좁힘·환율 상세 메뉴 선택이다. 정답 라벨을 사후 변경하지 않았다.
- 포괄적인 목표만 주어지면 추천 조합은 여러 가지일 수 있다. 필수/선택 업무와 허용 대체 메뉴는 사람의 검수가 필요하다. 기존의 여행 고정 3종 라벨을 없애거나 바꾸어 점수를 올리지 않았다.
- 실제 모델은 gpt-4.1-2025-04-14와 jev-1.14.0이다. 보조 LLM은 585개 메뉴 이름·설명을 참고하므로 이 결과는 LLM→E5→JEV 혼합 구조의 결과다. 최종 ID는 실제 E5 후보와 JEV 응답으로 검증한다.
- 업무별 Top20, 미해결 업무만 Top40으로 확대한다. 원문 근거 인용, 후보 내 ID, 중복·누락을 검사한다. 최대 8개 업무이며 초과 시 조용히 자르지 않는다. 동일 메뉴로 여러 업무가 합쳐지면 partial로 표시한다.
- Java 148개 중 142개 통과·6개 제외, 실패 0. 지표 테스트 3개 통과. 완료된 100개의 라벨·소스 해시·원문 근거·후보 포함·원시 사용량을 별도 검산했다.
- 평가 시작 후 추론 코드·임계값·라벨은 변경하지 않았다. 재개 도구는 저장된 문항 건너뛰기·속도 제한·오류 상세 기록만 추가했다. 개발 실패·토큰은 최종 평가와 별도 보관한다.
- 로컬 코드/결과 브랜치이며 GitHub 푸시·PR 게시는 하지 않았다. 기존 IntelliJ 체크아웃의 파일은 변경하지 않는다.
