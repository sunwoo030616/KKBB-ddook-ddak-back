## 범위와 해석

- 이번 지표는 실행 전에 승인한 여러 메뉴 조합 중 하나와 정확히 일치해야 성공이다. 관련 메뉴면 전부 인정하는 방식이 아니다. 필수 업무 누락·불허 추가·불필요한 중복·오류는 실패다. 단일 기준 메뉴와의 완전일치도 원시 결과에 별도로 남겼다.
- 이전 95%는 메뉴명 나열/원하는 기능이 드러난 다른 평가셋의 단일 정답 집합 지표였다. 이번 결과와 그대로 개선율로 비교하면 안 된다.
- 10개 상황을 10가지씩 표현한 합성 질문이다. 100개의 독립 상황·전문가 독립 검수·실사용 정확도가 아니다. 같은 상황군의 표현은 상관된 표본이다. 일반화는 추가 상황군과 실제 사용자 검증이 필요하다.
- 포괄 목표 50개와 상황·제약 50개를 구분했다. 단일 질문·무관 질문·확인 질문을 정답으로 넣어 분모를 늘리지 않았다. 모든 정답 조합은 최소 2개 메뉴다.
- 사용자는 여행 외 추천 묶음도 제품 평가 기준으로 승인했다. 이것은 모든 사용자에게 금융상품 가입을 권장한다는 의미가 아니며, 실제 이용 가능성·자격·거래 성공은 검증하지 않았다.
- 정답과 소스는 API 실행 전에 고정했고 결과를 보고 바꾸지 않았다. 특정 상황용 추천 분기는 추가하지 않았다. 실제 선택/형식 오류는 재시도하지 않았다.
- 단독 LLM은 간결한 ID·이름·설명 목록을 받는다. 혼합 구조의 JEV는 검색한 후보의 select_when도 받는다. 정의된 두 경로의 비교이며 모든 입력 상세 필드나 모든 단독 프롬프트의 최적화를 통제한 것은 아니다.
- HTTP 시간은 실제 응답 경로의 LLM/E5/JEV/proxy를 포함한다. 큐 대기·컴파일·모델/임베딩 준비는 제외한다. 각 조건 1회이고 네트워크·캐시·모델 변동성이 있다.
- 사용자 요청에 따라 한도 오류만 최대 4번까지 교체하고 이전 시도는 별도 보관한다. 그 시도의 토큰은 비교 합계에서 제외한다. 응답에 usage가 없으면 0으로 만들지 않는다. 비교 비용은 전체 청구액이 아니다.
- 비용은 공개 표준 단가와 관측 usage의 추정이다. 캐시 입력은 전체 입력의 일부다. JEV 출력은 무료이며 제공자별 토큰 총량을 동일 과금 단위로 비교하면 안 된다. 로컬 E5 CPU/호스팅·세금·계정별 요금 차이는 제외한다.
- 발표 페이지 구성은 취소 상태로 유지했다. GitHub에 게시하지 않았다. 기존 혼합 300문항·이전 비교의 부분 결과와 이번 결과를 합치지 않았다.
