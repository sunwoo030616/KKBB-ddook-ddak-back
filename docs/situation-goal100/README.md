## 읽을 때 주의할 점

- 100개의 서로 다른 표현이지만 **10개 승인 상황군 ×10개 표현**이다. 100개 독립 상황, 전문가 독립 검수, 실사용 전체 정확도가 아니다. 목표만 주는 50개와 상황·제약을 주는 50개로 구성했다.
- 부분 적중률은 여러 업무를 모두 해결했다는 의미가 아니다. 승인한 선택 추천 하나만 맞아도 부분 적중이 될 수 있다. 필요한 업무 누락과 허용 밖 메뉴는 별도 수치로 남긴다.
- 단독 LLM과 삼단계의 추천 수가 다르다. 더 많이 제시하면 부분 적중률이 높아질 수 있으므로 메뉴 적합 비율과 추천 수를 함께 비교해야 한다. 같은 첫 1/2/3개 응답 예산의 진단 수치는 partial-summary.json에 있다. 출력 순서는 전역 관련도 순위를 보장하지 않는다.
- 이전 95% 실험과 평가셋·정답 기준이 다르다. 기존 수치와 개선율로 직접 비교하지 않는다. 이번 부분 지표도 사용자 요청으로 실행 도중 추가한 것이며 사전 고정 지표였다고 표현하지 않는다.
- 두 경로는 동일 GPT-4.1과 동일 585개 메뉴를 사용한다. 단독은 ID·이름·설명, 삼단계는 업무 분해 후 실제 E5 후보와 JEV 선택을 사용한다. JEV에는 후보의 select_when도 있어 모든 상세 입력 필드가 동일한 실험은 아니다.
- HTTP 시간은 실제 요청 중 모델·검색·proxy를 포함하며 큐 대기·컴파일·모델 기동은 제외한다. 오류도 전체 평균에 포함했다. 각 조건 1회이며 네트워크·캐시·모델 변동성이 있다.
- 한도 오류만 교체하고 그 시도는 비교 토큰에서 제외한다는 사용자 지시를 적용했다. 오류에 usage가 없으면 0으로 만들지 않는다. 모델·형식·정확도 오류는 재실행하지 않았다.
- 비용은 관측 usage와 공개 표준단가의 추정이며 전체 청구액이 아니다. 캐시 입력은 입력의 일부이고 JEV 출력은 무료다. 로컬 E5 CPU/호스팅·세금·계정별 요금 차이·개발 및 제외 시도는 빠져 있다.
- 발표 페이지 구성은 취소 상태로 유지했고 GitHub에도 게시하지 않았다.
