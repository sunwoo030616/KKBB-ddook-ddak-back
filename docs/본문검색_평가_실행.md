# 본문 검색·복수 인용·분리 평가 실행

무료 로컬 모델과 이미 내려받아 해시를 확인한 파일만 사용한다. 서버 요청 중에 모델이나 논문을 내려받지 않는다. 기존 서비스 모델 준비는 [MCP·Skill 실행 안내](MCP_Skill_수집파이프라인_실행.md)를 따른다. 아래 명령은 저장소 루트에서 실행한다.

## 공식 PDF 준비와 본문 수집

```sh
mkdir -p var/fulltext
curl -fL --max-time 60 https://arxiv.org/pdf/2005.11401v4 -o var/fulltext/rag.pdf
curl -fL --max-time 60 https://proceedings.mlr.press/v202/leviathan23a/leviathan23a.pdf -o var/fulltext/speculative.pdf
.venv/bin/python scripts/enrich_literature_fulltext.py
```

`data/literature_fulltext_manifest.json`에 고정한 SHA256과 일치해야 수집한다. 원문 PDF가 배포처에서 바뀌면 실패하므로 새 파일을 검토하고 manifest 변경을 별도 기록한다. 기본 대상은 `var/knowledge.sqlite3`, 다른 DB는 `--db`로 지정한다. 최대 PDF 5MB, 첫 3페이지, 페이지당 12,000자를 허용한다. PDF 해석·정규화는 DB 갱신 전에 수행하고 두 문서의 변경은 하나의 트랜잭션으로 반영한다. 재실행하면 동일 버전은 변경하지 않는다.

본문은 초록 뒤에 페이지별로 덧붙인 버전 문서이며 `abstract_text`와 `fulltext.pages`에 원래 초록과 페이지 위치를 보존한다. 형식상 `kind=abstract`인 문서 중 두 편에 제한된 본문이 포함된다. 전체 논문을 수집했다는 뜻이 아니다. 원본 PDF와 추출 본문은 `var/`에 보관하고 Git에 올리지 않는다.

## 로컬 모델 평가

메모리가 제한된 Mac에서는 실행 중인 AI 서버와 별도 MLX 평가 프로세스를 중복으로 띄우지 않는다. 기존 서버를 관리하는 실행 방식에 맞춰 중지하고 평가 후 다시 시작한다. 모델 하나를 읽는 실제 평가를 한 번에 하나씩 실행한다.

```sh
export OPENAI_API_KEY=''
export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1
export RAG_EXACT_CACHE=0 RAG_SYSTEM_PREFIX_CACHE=1
export RAG_MLX_CACHE_MB=128 RAG_MPS_CACHE_POLICY=release

.venv/bin/python scripts/evaluate_fulltext_literature.py --suite regression --output reports/fulltext-regression.json
.venv/bin/python scripts/evaluate_fulltext_literature.py --suite preregistered --output reports/fulltext-preregistered.json
```

`--suite pilot`은 두 기존 누락 문항만 실행한다. `preregistered`는 `literature_evaluation_protocol.json`에 기록된 문항 파일 SHA256이 달라지면 실행하지 않는다. 개발자가 작성한 사전 고정 문항이며 외부 주석 데이터와 구분한다. 이미 공개한 결과를 덮어쓰기보다는 `--output`을 새 경로로 지정해 보존하는 편이 좋다. 지연은 프로세스 내 순차 요청 시간이며 생성 결과 캐시는 사용하지 않는다. 임베딩·재순위 캐시와 시스템 prefix 캐시는 별개다.

## 외부 주석 SciFact 표본

[공식 배포 안내](https://github.com/allenai/scifact)와 [데이터 라이선스](https://github.com/allenai/scifact/blob/master/LICENSE.md)를 따른다. Claims·evidence annotations는 CC BY 4.0, corpus(S2ORC)는 ODC-By 1.0이다. 출처는 Wadden et al., *Fact or Fiction: Verifying Scientific Claims*.

```sh
mkdir -p var/scifact
curl -fL --max-time 60 https://scifact.s3-us-west-2.amazonaws.com/release/latest/data.tar.gz -o var/scifact/data.tar.gz
.venv/bin/python - <<'PY'
import tarfile
from pathlib import Path
root=Path('var/scifact')
with tarfile.open(root/'data.tar.gz') as archive:
    for name in ('data/corpus.jsonl','data/claims_dev.jsonl'):
        member=archive.getmember(name)
        if not member.isfile() or member.size>20_000_000:
            raise ValueError('invalid_dataset_member')
        (root/Path(name).name).write_bytes(archive.extractfile(member).read())
PY
.venv/bin/python scripts/prepare_scifact_evaluation.py
.venv/bin/python scripts/evaluate_scifact_external.py
```

`prepare`는 seed·주장 ID·문서 ID·원본 해시를 `data/scifact_external_protocol.json`과 비교한다. 고정 프로토콜이 바뀌면 실패한다. 표본은 SUPPORT 단일 정답 주장 10개, 정답 문헌과 무작위 방해 문헌을 포함한 200개 문서이며 전체 벤치마크 점수가 아니다. 결과를 본 뒤 표본·문항·검색 설정을 조절하지 않았다. `var/scifact/evaluation.sqlite3`는 제품 DB와 분리된다. 정답 label과 근거 문장 번호는 평가기에만 주고 검색기·LLM에는 전달하지 않는다.

`document_hit`와 연구자가 주석한 근거 문장 포함률을 따로 계산한다. 같은 문장의 겹치는 인용을 합집합으로 계산해 이중 집계를 막는다. 여러 대안 근거 집합은 가장 잘 포함된 집합을 기준으로 한다. 문장 일치만으로 함의·참/거짓 분류를 입증하지 않는다.

## 실제 API·MCP와 요약

AI 서버 8767을 다시 실행하고 다음을 수행한다. MCP 의존성은 `requirements-mcp.txt`에 있다.

```sh
.venv/bin/python scripts/verify_fulltext_platform.py
.venv/bin/python -m pytest tests_rag -q
.venv/bin/python scripts/summarize_fulltext_evaluation.py
```

요약기는 세 보고서의 완료 여부와 현재 백엔드·문항·프롬프트 SHA256을 대조한다. 최초 평가 후 scope guard만 고친 경우는 before/after hash 감사와 실제 API 검증을 갖춘 명시적 예외로 처리하고, 수정 전 최초 점수를 그대로 설명한다. 다른 코드 변경을 오래된 평가로 요약하지 않는다. 실패한 v4 프롬프트와 첫 느린 파일럿도 별도 보고서로 남긴다. 라이브 검사는 인용 페이지 재조회·문서 변경 없음·검토 상태 변경 없음·유료 API 미설정을 확인한다.
