# 모델 비교와 문헌 검색 경로

최신 기본 경로는 `adaptive`이며 [병목 분석·플랫폼 개선](문헌검색_병목분석_플랫폼개선.md)과 [실행 안내](MCP_Skill_수집파이프라인_실행.md)에 정리했다. 아래는 이전 경로들의 비교·재현 기록이다.

현재 수치와 면접 설명은 [무료 모델 개발 결과](무료모델_개발결과_면접정리.md), 작업 운영은 [지식 큐레이션](지식큐레이션_운영과_면접.md)에 정리한다. 모든 생성은 무료 로컬 모델을 사용한다.

## 준비

기존 MLX 4B·1.7B와 BGE 준비는 `rag_backend.prepare_research_models`의 명시적 다운로드 명령을 사용한다. 추가 영어 모델 두 개는 다음 명령으로 준비한다. 추론 요청 중 다운로드하지 않는다.

```bash
.venv/bin/python scripts/prepare_literature_reranker.py
.venv/bin/python scripts/prepare_literature_reranker.py --encoder
.venv/bin/python scripts/collect_research_corpus.py
```

영어 모델은 `cross-encoder/ms-marco-MiniLM-L6-v2`와 `sentence-transformers/all-MiniLM-L6-v2`다. 리비전·파일 해시를 기록하고 적재 전에 파일을 검증한다. 원래 한국어 금융 위젯 검색의 다국어 모델과 역할을 구분한다.

## 문헌 API

`POST /knowledge/research`의 기본은 `adaptive`다. 아래 이전 경로도 내부 연구·검수 실험 옵션으로 명시적으로 요청할 수 있다.

| mode | 동작 |
| --- | --- |
| adaptive | 원문 다국어 검색과 불확실한 후보의 선택적 검증; 현재 기본 |
| single | 요청 전체 검색 |
| decompose | 모델의 원문 부분 인용과 질의 분해 |
| compact | 대상 개수 분류 뒤 짧은 영어 질의 |
| fast | compact에 구절 임베딩 선별 추가; 이번 장비의 지연 악화로 기본 채택하지 않음 |
| contextual | 겹치는 문장 문맥으로 검색 구절 구성 |
| anchored | 서버 원문 절 경계에 맞춰 질의 생성, 문장 문맥과 후보 예산 사용 |

`anchored`는 쉼표·명시적 나열·요청 대상의 접속 표현을 사용하는 표면 규칙이다. 일반적인 한국어·영어 의미 파서가 아니며 암시적인 비교나 잘못 나눈 절은 한계로 남는다. 원문 시작·끝 위치를 서버가 관리한다.

근거 선택의 기본 `binding_format`은 `ids`다. `ordinal`은 고정된 작업별 인덱스 스키마를 비교하는 실험 옵션이다. 실제 인덱스 범위와 원문 버전은 서버가 다시 검사한다. JSON 유효성이 의미 정확도를 보장하지 않는다.

## 로컬 실행 설정

```bash
RAG_SYSTEM_PREFIX_CACHE=1 RAG_MLX_CACHE_MB=128 \
RAG_MPS_CACHE_POLICY=release \
LITERATURE_RERANKER=tiny LITERATURE_DENSE_POOL=10 \
.venv/bin/python scripts/dev_stack.py
```

시스템 KV는 사용자 토큰을 저장한 대화 캐시가 아니다. 정확한 prefix+suffix 토큰열 일치를 검사하고 시스템 prefix의 KV만 복제해 사용한다. 결과 메모이제이션, 디코더 스키마 캐시, 점수 캐시, 문서 벡터 캐시는 별도로 동작한다.

## 실제 비교와 재현

오프라인 모델 실험은 이미 실행 중인 모델 서버를 중지한 후 하나씩 실행한다. 동일한 16GB Mac에 모델 복사본을 중복 적재하면 지연이 왜곡될 수 있다.

```bash
# 변경된 문서만 후보 생성; 실제 카드의 승인은 별도 CLI 작업
.venv/bin/python scripts/refresh_knowledge.py

# 6편 기준 두 생성 모델과 검색 경로 비교
.venv/bin/python scripts/compare_model_routes.py

# 30편 기준 문헌 경로 진단
RAG_SYSTEM_PREFIX_CACHE=1 RAG_MLX_CACHE_MB=128 \
.venv/bin/python scripts/evaluate_literature_profile.py \
  --mode anchored --dense-candidates --binding-format ids

# 단독 절 생성·고정 인덱스는 검증된 기본 경로와 구분한 실험
RAG_SYSTEM_PREFIX_CACHE=1 RAG_MLX_CACHE_MB=128 \
.venv/bin/python scripts/evaluate_literature_profile.py \
  --mode anchored --dense-candidates --per-clause --binding-format ordinal

.venv/bin/python scripts/evaluate_expanded_retrieval.py --bge-max-seconds 1200
```

BGE 시간 예산은 질의 사이에서 검사하며 진행 중인 한 질의를 강제 취소하지 않는다. 실제 실행은 일부 검색이 50초를 넘는 자원 제약으로 수동 중단한 기록을 포함한다. 완료 문항 수를 그대로 표시하고 모든 경로가 완료한 동일 영어 질의의 교집합을 별도로 비교한다. 중단한 순서의 부분집합을 무작위 표본이나 전체 60문항 결과로 해석하지 않는다.

JSON 보고서에 모델 리비전, 데이터 해시, 원문 버전, 단계별 시간, 초기 컴파일, 캐시 여부와 실패를 남긴다. 기존 21.20초와 새 경로는 corpus와 실행 조건이 달라 단일 수정의 인과적 향상률로 계산하지 않는다. 느리거나 의미 오류가 증가한 구성은 기본에 승격하지 않는다.

기술 참고: [Retrieve & Re-Rank](https://www.sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html), [영어 재평가 모델](https://huggingface.co/cross-encoder/ms-marco-MiniLM-L6-v2), [영어 문장 임베딩](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2).
